# Icons App

Downloads for Icons App, a Mac app for icons, emoji, clip art and stock images.

**[Download the latest version](../../releases/latest)** (Apple silicon Macs).

Open the DMG and drag Icons App to Applications. The app isn't notarised, so the first time, right-click it and choose **Open**. If macOS still blocks it, go to System Settings › Privacy & Security and click **Open Anyway**.

From version 1.5.0, Icons App updates itself from this page.
